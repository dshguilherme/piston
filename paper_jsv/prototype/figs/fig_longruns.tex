% F27 Long runs (Experiment 8): level re uniform against iteration for the continued runs.
% (a) design point, exact-driven run X0 continued to the stopping rule; (b) 90 deg cap, kR = 1.5: exact runs
% from uniform (XU) and from the sinc design (XS), sinc run from uniform (SU, true and predicted level).
% Higher = more power; 0 dB = uniform design. Every value is the running pick (lowest own objective so far,
% feasible). Data: data/f27_*.dat and data/f27_numbers.tex from tests/r0_fig_longruns.py. Drawn at 137 mm.

\usepackage{amsmath,amssymb,bm}

}

  predcurve/.style={witness, draw=figsurr, dash pattern=on 1pt off 1pt},
